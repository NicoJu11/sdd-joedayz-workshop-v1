# SDD Workshop Boost Templates

Reusable templates for the Skill-Driven Development (SDD) Workshop Boost product. Provides starting points for workshop participants to structure their projects and learnings.

## Contents

- `CLAUDE.md` -- Template CLAUDE.md for workshop participant projects
- `LEARNINGS.md` -- Template for capturing workshop learnings
- `skill-template.yaml` -- Template for creating Claude Code skills
